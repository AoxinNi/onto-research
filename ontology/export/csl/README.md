# Citation styles

These CSL files are copied unchanged from the official repository of the Citation Style Language project,
<https://github.com/citation-style-language/styles> (master branch, fetched 2026-11-08). Each file names its authors
and contributors in its `<info>` element.

They are licensed under the Creative Commons Attribution-ShareAlike 3.0 Unported license
(<https://creativecommons.org/licenses/by-sa/3.0/>). If you change one, keep the attribution, say what you changed in
its `<info>` element and give it a new `<id>`; the changed file is under the same license.

| `chicago-author-date.csl` | `chicago-author-date`, Chicago Manual of Style author-date |
| `ieee.csl` | `ieee`, IEEE |
