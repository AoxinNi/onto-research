MODEL CONTEXT PROTOCOL

MCP 接入

本体的全部能力都以 MCP 工具提供。工作台右侧的 agent 用的就是这一套；Claude Code、Claude Desktop 等客户端按下面的配置接入后，能做的事完全一样。接受和拒绝改动是人的决定，不是工具。

外部 MCP 服务 0

接入后，工作台的 agent 可以直接调用这些服务的工具；在「数据源」里还能把某个工具设成定时采集的数据源，用来盯市场。请求头只保存在本机的 ~/.config/onto-research/mcp.json，页面上只显示末尾 4 位。

需要 magpie 吗？

            
MCP 客户端（Claude Code、Claude Desktop、Cursor…）用它自己的模型思考，本体服务只提供工具，本身不调用模型。所以大部分情况不需要 magpie，只有下面标出的工具例外。

    Big Bang：合并项目
    
      
    选两个或更多项目，它们的图谱、文献（含 PDF、精读）、摘录、笔记和论文会合并进一个新项目。原项目保持不变。
    
      
    
      
      
      
    同类型同名的节点、同一 DOI 的文献会合成一个，笔记里的引用随之改写；引用键撞车的文献会换一个新引用键。PDF 只存一份，由新旧项目共用，合并几乎不占额外空间。对话记录和待审核的改动留在原项目。
